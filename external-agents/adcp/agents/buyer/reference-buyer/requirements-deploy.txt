# `agentcore`; see deploy_all.agentcore_cli() for how the npm one is resolved when both are present.
#
# deploy_all.py's step 0.1 (bootstrap-venvs) installs THIS file into the buyer's .venv, so the deploy
# scripts can import the toolkit while the image stays free of it.
